# Panier Pesé

Application web qui catégorise les dépenses **ligne par ligne** depuis les tickets
de caisse — pour suivre son budget ET ses habitudes (alimentation, boissons, tabac…).

## Le problème

Les applications bancaires catégorisent paiement par paiement : un passage
au supermarché devient « courses » sans détail. Impossible de savoir combien
représentent l'alcool, les produits bruts, les produits ultra-transformés,
les restaurants par opposition aux fast-foods…

## La solution

- 📷 Photo du ticket de caisse, lecture **ligne à ligne**
- 🏷️ Catégorisation fine des articles (produits bruts, ultra-transformés, alcool, vices…)
- 📊 Cumuls par catégorie et par mois
- 🔒 **100 % local** : les données ne quittent jamais l'appareil
- 📥 Export / import pour ne rien perdre
